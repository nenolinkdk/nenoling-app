# Portuguese pack / LearnPortuguese2 migration area

Reserved for mapping LearnPortuguese2 into the Nenoling template.

The exact support/target direction and locales must be confirmed from the existing LearnPortuguese2 product before generating a manifest.

Portuguese-specific grammar and conjugation structures should be preserved and represented as language-pack content rather than removed to imitate FR-DA.

See `docs/LEARNPORTUGUESE2_MIGRATION.md`.
